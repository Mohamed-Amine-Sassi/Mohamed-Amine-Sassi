### ⚙️ Featured build — MoneyPersona

An explainable, auditable agentic pipeline (not a chatbot, not anomaly detection) that classifies bank clients into personas and generates grounded narrative + visual specs.

```
FetchFeatures → validate_data ──┬── ColdStartPersona (no data)
                                 └── ClassifyPersona (rule-based)
                                          │
                                    EnrichContext (peer + seasonal)
                                          │
                              GenerateNarrative (LLM) → GenerateVisualSpec (LLM) → END
```

- Deterministic, explainable classification — LLM calls reserved for narrative & visual spec generation only, always grounded in pre-computed facts
- Stack: `Python` · `FastAPI` · `LangGraph` · `LangChain` · `ChatGroq (Llama 3.3 70B)` · `MongoDB`
- Frontend reveal experience in `React` · `Framer Motion` · `Recharts`
